## How the site works

A static site built with plain HTML, CSS, and JavaScript. It has no build step. GitHub Pages publishes the `main` branch, so a change is live a minute or two after it's pushed.

| File | Contents |
| --- | --- |
| `index.html` | Page structure and most of the text |
| `script.js` | Skills, experience, and project data, plus interactive features |
| `styles.css` | Layout, colors, and light/dark themes |
| `Revathi_Gollapelli_Resume.pdf` | Résumé offered for download |

To preview locally, open `index.html` in a browser.
